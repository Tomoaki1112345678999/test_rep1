# 要件定義書：技術記事キュレーション「TECH TIMES」

本ドキュメントは、実装着手前にユーザーと合意した要件をまとめたものです。

## 1. 目的・コンセプト

QiitaとZennに投稿された技術記事のうち、**いいね/LGTM数が多い人気記事**を集約し、
**日経新聞風の紙面レイアウト**で一覧配信するWebアプリ。

## 2. 機能要件

### 記事収集（ビルド時バッチ）

- **ソース**: Qiita（公式API v2）＋ Zenn（公開JSON API）
- **ランキング指標**: いいね/LGTM数（Qiita=`likes_count` / Zenn=`liked_count`）
- **集計期間タブ**: 日間 / 週間 / 月間（既定 = 週間）
- **更新頻度**: 6時間ごと（GitHub Actions の cron）
- 重複排除・各記事に出典バッジ（Qiita / Zenn）を付与
- 取得失敗時はサンプルデータにフォールバックし、サイトを壊さない

### 表示（フロント）

- **表示内容**: タイトル＋著者＋いいね数＋出典＋短い概要（抜粋）＋**元記事へのリンク**
  - 本文は転載しない（著作権・各サービス規約上の安全性を優先）
- **レイアウト**: 日経新聞風
  - マストヘッド（紙名＋日付）
  - トップに大見出しのリード記事＋サブ記事
  - マルチカラムのグリッド、明朝体見出し、罫線区切り
  - ソース別ランキング（Qiita / Zenn）のサイドバー
  - 期間切替タブ
- レスポンシブ（iPad / スマホ / PC 対応）

## 3. 非機能要件

- **ホスティング**: GitHub Pages（完全無料・サーバ不要）
- **構成**: GitHub Actions が記事取得 → ランキング → 静的サイト生成 → Pages へ自動デプロイ
- APIキー不要（Qiitaは未認証でも閲覧系API利用可。任意で `QIITA_TOKEN` を Secrets 追加可能）

## 4. マネタイズ

- 初期は**無し**。将来 Google AdSense を導入しやすい構成を保つ。
- 本文を転載せず出典明記＋元リンク誘導とすることで、規約・著作権リスクを回避。

## 5. 技術スタック

- **Astro + TypeScript + Tailwind CSS v4**（モダンなSSG構成・静的出力）

## 6. スコープ外（初期）

- ユーザー登録・お気に入り・コメント
- 全文表示・記事のDB保存
- はてなブックマーク等の追加ソース（将来拡張）

## 合意事項（選択結果）

| 項目 | 決定 |
| --- | --- |
| 記事ソース | Qiita + Zenn |
| 表示方法 | タイトル + 概要 + 元リンク（本文非転載） |
| ホスティング | GitHub Pages + Actions |
| マネタイズ | 初期は無し（後で追加） |
| 技術スタック | Astro + TypeScript + Tailwind |
